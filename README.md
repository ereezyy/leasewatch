# LeaseWatch waitlist

Public waitlist page for LeaseWatch, a tool that helps type-beat producers track beat-lease stream caps and upgrade opportunities.

The site is a static page meant to be served from GitHub Pages at the repository root (`index.html`).

## Web3Forms key (required for signups)

1. Open https://web3forms.com and enter the email that should receive waitlist signups.
2. Copy the access key from the email Web3Forms sends.
3. In `index.html`, replace the single placeholder `WEB3FORMS_ACCESS_KEY_PLACEHOLDER` with that key.

Until the key is in place, the form does not submit and shows "Signups opening shortly."
